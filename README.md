# ozelserkan.com

Personal academic website of Serkan Özel, in Turkish and English, published with GitHub Pages.

- `src/` — the pages, layouts and site data, built with [Eleventy](https://www.11ty.dev/).
- `design/` — the design system: brand book, tokens, component styles and logos.
- `notes/content-plan.md` — the agreed content of each page.
- `CLAUDE.md` — working instructions for Claude Code.
- `CNAME` — the custom domain for GitHub Pages.

To preview locally: `npm install` once, then `npm start` and open http://localhost:8080.

Pages will be added as they are agreed; see the sitemap in `CLAUDE.md`.
