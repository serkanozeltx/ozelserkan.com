# Logos

- `so-mark.svg` — the pattern mark for light grounds (`paper`, `paper-raised`): discs in `strait` #0e5a5c, squares in `clay` #a8441f, the open fifth unit outlined in `ink-muted` #565e6a.
- `so-mark-dark.svg` — the same mark for dark grounds: `strait` #6cbcb5, `clay` #ec8a62, outline `ink-muted` #a4abb4.
- Set the name beside it in Newsreader 600, `ink`, with a `space-3` gap. Minimum height 12px. Keep clear space of one unit (the disc's width) on every side.
